# CEDETEC - Formulario de Auditoría Digital

Formulario web para capturar información de auditoría de negocios locales.

## Características

- Formulario responsivo con diseño profesional
- Conexión automática con Google Sheets
- 5 preguntas clave de diagnóstico
- Integración con Apps Script de Google

## URL en vivo

https://cedetec-ti.github.io/cedetec-auditoria/

## Archivos

- `index.html` - Formulario principal
