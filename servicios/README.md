# 🔧 Carpeta: Servicios

Contiene las páginas de servicios individuales de CEDETEC.

## Estructura de Servicios

Cada archivo sigue el mismo patrón:
1. **Hero section** - Título y descripción del servicio
2. **¿Qué es?** - Explicación clara
3. **6 Beneficios** - Ventajas principales
4. **6 Casos de uso** - Industrias/situaciones donde aplica
5. **CTA** - Llamada a acción (WhatsApp)

## Archivos

### 6 Servicios Disponibles
- **automatizacion.html** - Automatización de procesos
- **inventario.html** - Control de inventario
- **clientes.html** - Gestión de clientes (CRM)
- **turnos.html** - Sistema de turnos y citas
- **analisis.html** - Análisis de datos
- **integracion.html** - Integración de sistemas

## Estructura de URL
```
https://cedetec-ti.github.io/cedetec-auditoria/servicios/[nombre].html
```

## Agregar nuevo servicio

1. Copiar cualquier archivo (ej: automatizacion.html)
2. Cambiar el título, descripción y emoji
3. Actualizar los 6 beneficios
4. Actualizar los 6 casos de uso
5. Actualizar el mensaje de WhatsApp
6. Agregar link en servicios.html

## Links relacionados
- Servicios principales: `/servicios.html`
- Home: `../` o `index.html`
- Auditoría: `../auditoria.html`
